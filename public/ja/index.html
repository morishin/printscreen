macOS のスクショを、もっと便利に

標準のスクリーンキャプチャの代わりに。撮ったらすぐ書き込めて、ファイルは自動で軽くなります。

Mac 版をダウンロード GitHub

無料・オープンソース。macOS 26 以降に対応。

01

macOS 標準のキャプチャを置き換える

スクリーンショットも画面録画も、いつものショートカットで。

⌘⇧3画面全体⌘⇧4範囲・ウインドウ⌘⇧5録画

クリックとキー入力も見える

録画中のクリックを波紋で、押したキーを右下に表示できます。操作の手順がそのまま伝わります。

02

文字、矢印、枠をすぐ入れられる

撮影するとすぐに編集画面が開きます。伝えたい場所を示し、隠したい情報にはモザイクをかけられます。

03

WebP / WebM で自動的に軽く

スクリーンショットは WebP、録画は WebM で保存。変換の手間はいりません。
PNG、JPEG、MP4、MOV も選べます。

画面録画

このページのサンプル画像とデモ動画での実測値です。削減率は内容によって変わります。WebM には ffmpeg が必要です（brew install ffmpeg）。
